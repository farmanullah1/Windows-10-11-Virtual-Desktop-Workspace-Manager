# UI & UX Specification

## 1. Design Philosophy

The **Virtual Desktop Workspace Manager** interface is designed as a serious, professional Windows desktop productivity utility adhering to the following core tenets:

1. **Progressive Disclosure:** Present high-level status and primary actions first. Technical details (HWND, PID, COM GUIDs, matching rules) are available on demand via detail dialogs and drawers rather than cluttering primary workflows.
2. **One Clear Primary Action:** Each view highlights a single primary button with prominent visual styling (`Primary.TButton`), while secondary actions use understated styles.
3. **Never Color Alone:** Colors are always reinforced with text and symbols (`✓ Verified`, `⚠ Warning`, `✕ Error`, `○ Idle`) to ensure full accessibility for color-blind users and high contrast compliance.
4. **Predictable & Safe State Changes:** Harmful or state-altering operations require confirmation and clearly delineate what will happen and what will not happen (no process killing, no file deletion).
5. **Zero Silent Discard:** Configuration edits are tracked with an explicit dirty indicator (`● Unsaved Changes`) and protected with exit/navigation prompts.

## 2. Information Architecture

The main application window is structured into three primary vertical zones:

```text
┌────────────────────────────────────────────────────────────────────────┐
│ Header Toolbar (Title, Active Profile, Health Badge, Emergency STOP)   │
├────────────────────────────────────────────────────────────────────────┤
│ 10-Tab Navigation Notebook                                            │
│ [Dashboard] [Workspaces] [Applications] [Virtual Desktops] [Execution]│
│ [History] [Logs] [Diagnostics] [Settings] [About]                      │
├────────────────────────────────────────────────────────────────────────┤
│ Status Bar (Status message, Unsaved Changes warning, Provider status)  │
└────────────────────────────────────────────────────────────────────────┘
```

## 3. Screen Specifications

### 3.1 Dashboard
- **Workspace Status Banner:** Displays active profile status (`✓ Workspace Ready & Configured` or `⚠ N Applications Missing`).
- **Metric Cards Grid:** 4 structured summary cards: Total Desktops, Configured Apps, Running Apps, Warnings/Missing.
- **Quick Actions Bar:** Primary action `▶ Launch Workspace` flanked by `⟳ Sync Workspace`, `🔍 Dry Run`, `↻ Refresh`, and creation buttons.
- **Active Workspace Overview:** Scrollable cards showing each configured desktop and badges for assigned apps.
- **Recent Activity Footer:** Real-time summary of the most recently executed operation with quick link to History.

### 3.2 Workspaces (Editor)
- **Desktop Cards:** Grouped by virtual desktop. Each card provides desktop switching, renaming, app addition, and deletion.
- **Application Rows:** Displays detection status (`✓ Running`, `⚠ Not found`, `○ Stopped`), app name, window policy, and actions (`Move to...`, `Edit`, `Test Match`, `Remove`).
- **Immediate Reassignment:** `Move to...` allows choosing a target desktop and optionally moving the running window immediately.

### 3.3 Applications
- **Toolbar:** Real-time search entry (`Ctrl+F`), Desktop filter dropdown, Status filter dropdown (`All`, `Running`, `Stopped`, `Missing Executable`), and result count indicator.
- **Treeview Table:** Structured view of all applications showing Status, Name, Desktop, Launch Mode, Window Policy, and Executable path.
- **Actions:** Edit Application, Move to Desktop, Diagnostic Test Match, and Safe Remove.

### 3.4 Virtual Desktops
- **Mapping Table:** Visualizes correlation between logical workspace desktops and Windows OS desktops.
- **Columns:** Workspace Desktop name, Windows Desktop number, Identity/Existence status (`✓ Exists` / `⚠ Missing`), Active Indicator (`[CURRENT ACTIVE]`), and Assigned Apps summary.
- **Actions:** Refresh, Switch View, and Create Missing Desktop.

### 3.5 Execution & Plan
- **Pre-Execution Plan Review:** Displays grouped actions (`DESKTOPS`, `APPLICATIONS`, `WARNINGS`) generated by Dry Run.
- **Live Progress Area:** Displays current step with animated progress bar during execution.
- **Outcome Summary:** Comprehensive post-execution report dialog showing created desktops, moved windows, warnings, and elapsed time.

### 3.6 Operation History
- **Audit Table:** Chronological table listing Timestamp, Profile, Operation, Result, Duration, and Operation ID.
- **Details Drawer:** Selection displays full summary, warnings list, and errors list.
- **Actions:** Copy Operation ID, Rerun as Dry Run, and Clear History.

### 3.7 Logs
- **Live Tail View:** Displays sanitized logs with custom level badges (`SUCCESS`, `INFO`, `WARNING`, `ERROR`).
- **Filter Controls:** Free-text query and level dropdown.
- **Tools:** Export to file, Clear visible buffer, and Open logs folder in File Explorer.

### 3.8 Diagnostics & Recovery
- **10 Categories:** System, Virtual Desktops, Provider, Configuration, Applications, Windows, Permissions, Storage, Dependencies, Recent Errors.
- **Status Badges:** `✓ Passed`, `⚠ Warning`, `✕ Failed`.
- **Tools:** Run Health Check, Copy Report, Generate Support Bundle (ZIP).
- **Crash Recovery:** Prompts user if an interrupted operation marker is detected from an unexpected shutdown.

### 3.9 Settings
- **Categorized Sections:** General, Appearance, Execution Timings, Safety, Startup Automation, System Tray, Logging.
- **Validation Bounds:** Enforces non-negative values, minimum window timeouts (1000ms), and bounded retries.

### 3.10 About
- **System Information:** OS version, build, runtime, provider name, integrity level, offline status.
- **Shortcuts Reference:** Cheatsheet of native accelerator keys.

## 4. Accessibility & Responsiveness

- **Keyboard Traversal:** Logical tab order across all interactive controls.
- **Accelerators:** Native shortcuts (`Ctrl+S`, `Ctrl+R`, `F5`, `Ctrl+F`, `Ctrl+L`, `Ctrl+,`, `Esc`).
- **Contrast & Fonts:** Uses standard Windows `Segoe UI` and `Consolas` fonts with high-contrast color tokens adhering to WCAG AA.
- **DPI Scaling:** Responsive geometry minimum size `920x680` supporting 100%, 125%, 150%, and 200% Windows display scaling.
